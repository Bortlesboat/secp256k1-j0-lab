# Lessons

## 2026-10-10 — Test symmetry claims over the full toy relation set

The first nondegenerate `f3` relation selected on the `p = 31` curve happened
to survive a one-coordinate cube-root rotation. That did not generalize to the
full relation set. Future symmetry experiments should enumerate all relations
on small fields—or use a proved identity—before classifying an action as an
invariance or obstruction.
